# COLORS - LAMP Stack Application

## Overview

COLORS is a web application built using the LAMP stack (Linux, Apache, MySQL, PHP). 
The application allows users to log in and manage color records using PHP API endpoints connected to a MySQL database.


---

## Technologies Used

- Linux
- Apache
- MySQL
- PHP
- HTML
- Git & GitHub

## Setup

1. Install a LAMP stack.
2. Clone this repository.
3. Move the project to `/var/www/html/`.
4. Update the database credentials inside the PHP files.
5. Restart Apache.
